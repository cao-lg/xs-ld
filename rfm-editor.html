① 客户清单 ② 打分参数 ③ 分群标签 ④ 误区词云 ⑤ 知识点 ⑥ 文案

可视化编辑全部参考数据，无需手改 JSON。点 保存（本地） 写入浏览器，与主程序共用同一存储，打开主程序即生效； 点 导出 JSON 下载 rfm-config.json，提交到仓库根目录后，所有人用主程序的「一键更新」即可同步。

① 客户清单（姓名 / R 最近天数 / F 频次 / M 金额）

每行一位客户。R 越小代表越近期消费，F/M 越大越好。可增删客户。

② 打分参数

五分位档数（默认 5）：把每位客户的 R/F/M 按分位切成 1–5 分，5 为最优。

③ 8 类客户群标签 / 配色 / 说明

标签须与分群规则对应（2³ 全组合：重要价值 / 重要挽留 / 重要发展 / 一般保持 / 潜力价值 / 一般发展 / 新客培育 / 一般挽留）。分群规则由主程序按 R/F/M 分计算。

④ 常见误区词云（关键词 + 权重）

权重越大，误区词云中字体越大。

⑥ 文案（欢迎语 / 提示 / 免责）

⑤ 课堂知识点注解（标题 + 注解）

课堂讲解用的概念卡片，可增删。主程序「课堂知识点注解」按钮展开对照。
